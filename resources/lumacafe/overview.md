# LUMA Café, Bar & Lounge

These pages document **1.0.0** by **Goonsquad Studios**. The resource folder is **gs-lumacafe**.

LUMA is a four-level venue with a café and bar, private lounge, event floor, and a rooftop bar and swimming pool. Its lift has a touchscreen in the cabin, call buttons and live displays on all four landings. The server synchronizes the car and doors for nearby players.

| Item | Details |
|---|---|
| Venue | vector3(-376.0, 271.4, 84.28) |
| Runtime | FiveM with OneSync |
| Framework | Standalone, with optional Qbox, QBCore or ESX job checks |
| Interactions | Key prompt, ox_target or qb-target |
| Storage | No database |
| Commands | None |

The map provides spaces for roleplay and a working lift. Café sales, staff jobs and door locks are configured through your server's gameplay resources.

Start with [Installation](installation.md), then use [Configuration](configuration.md) to set up your preferred interactions and floor access.
