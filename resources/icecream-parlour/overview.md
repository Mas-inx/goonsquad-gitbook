# GS Ice Cream Parlour

These pages document **1.0.0** by **Goonsquad Studios**. Install the resource as **gs-icecream-parlour**.

The script runs the SWIRLZ parlour at three configurable locations. Each shop has four crafting machines, customer tablets and trays, an order monitor/TV, supplies, storage and a boss desk. The default shops use separate jobs and society accounts.

| Requirement | Setup |
|---|---|
| Framework | Qbox, QBCore or ESX |
| Database | oxmysql |
| Networking | OneSync |
| Inventory | ox_inventory, qb-inventory, qs-inventory or supported framework fallback |
| Interaction | ox_target, qb-target or native E/G prompts |
| Map | Matching SWIRLZ MLO installed separately |
| Release UI | Included, with local font; no build step |

The streamed files include machines, moving parts, product props and consumption animation. The building map is not included. Default shop positions are Hawick (-46.3489, -86.1914, 56.79), Mirror Park (1159.46, -298.83, 68.11) and Del Perro (-2006.48, -486.7524, 10.61).

See [Installation](installation.md), [Configuration](configuration.md) and [Usage](usage.md). No public or test commands are registered.
