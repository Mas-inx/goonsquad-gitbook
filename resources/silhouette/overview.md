# GS Nail Salon — Silhouette

These pages document **1.0.1** by **Goonsquad Studios**. The installable resource name is **gs_nailsalon**.

The delivery replaces Korean Plaza in Little Seoul with the salon/interior and exterior map assets, pedestrian navigation, vehicle paths and scenario files. Client scripts add a local receptionist, target interaction, camera and an editable venue directory.

| Item | Delivery |
|---|---|
| Location | Around vector3(-590.0, -1126.0, 21.2) |
| Receptionist | vector4(-596.18, -1120.64, 22.26, 357.1) |
| Required game build | 3258 for the supplied scenario-region list |
| Framework | Standalone; optional Qbox/QBCore/ESX character-gender checks |
| Target interaction | ox_target or qb-target; export fallback without a target |
| Storage | No database or persistent player data |
| Commands | None |

The directory ships with five editable venue entries. Their coordinates and action buttons are not configured by default, and floor labels are hidden. Referenced gameplay packages, jobs, door locks, inventories and treatment/payment systems are separate integrations.

Read [Installation](installation.md) before starting this map, especially its build and scenario-list conflicts. Existing installations should use [Updating to 1.0.1](updating.md).
