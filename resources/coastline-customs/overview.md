# GS Coastline Customs

These pages document **1.0.0** by **Goonsquad Studios**. The resource folder and server.cfg entry are **gs_coastlinecustoms**.

| Item | Value |
|---|---|
| Location | vector3(-1679.28, -769.24, 9.20) |
| Building heading | 140 degrees |
| Framework | Standalone; works alongside Qbox, QBCore and ESX |
| Database / UI build | None |
| Required external scripts | None for the map |
| Commands / exports | None |

The delivery contains the streamed map and client support for vanilla-object hides, animated signage/fans, the rooftop fire feature, a display forklift, ambient-pedestrian cleanup and interior room visibility. It does not install a mechanic job, repair script, business storage, vehicle tuning or door-lock rules.

Start with [Installation](installation.md). For editable files see [Configuration & Integration](configuration.md); for the custom door list see [Doors](doors.md).
